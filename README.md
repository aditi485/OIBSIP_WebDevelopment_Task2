OIBSIP Web Development - Task 2 💻 Personal Portfolio Website Objective

The objective of this project is to create a personal portfolio website that showcases personal information, technical skills, projects, and contact details.

The website works as a digital résumé and provides visitors with an overview of the developer's background and abilities.

🛠️ Technologies Used HTML5 CSS3 Visual Studio Code Git GitHub 📌 Steps Performed Created the HTML structure of the portfolio website. Designed a modern and professional user interface using CSS3. Added a fixed navigation bar. Created a hero section containing the name, role, introduction, and avatar. Added an About Me section. Created a responsive skills grid. Added project cards containing project descriptions and GitHub links. Added a contact section with email, GitHub, and LinkedIn links. Implemented smooth scrolling between sections. Added responsive CSS using Grid, Flexbox, and media queries. Tested the website on desktop and mobile screen sizes. ✨ Features Professional hero section. About Me section. Technical Skills section. Projects section. GitHub project links. Contact information. LinkedIn and GitHub links. Smooth scrolling navigation. Responsive design. Modern dark theme. Cyan and purple accent colors. Hover effects and interactive elements. 📑 Sections Included Home

Introduces the developer with their name, role, short description, and call-to-action buttons.

About

Provides a brief introduction about the developer's background and interests.

Skills

Displays technical skills in a clean responsive grid.

Projects

Shows completed or placeholder projects along with descriptions and GitHub links.

Contact

Provides contact information and social media links.

🎯 Outcome

A responsive and visually polished personal portfolio website was successfully created. The website presents the developer's profile, skills, projects, and contact information in a clean and professional format.
